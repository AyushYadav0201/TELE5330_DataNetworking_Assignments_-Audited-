# TELE5330 Data Networking Assignments – Audited

This repository contains all assignments and solutions for **DATA NETWORKING (TELE5330)**, completed during the **Summer 2025 semester**.  
The assignments focus on core networking concepts, practical simulations, and troubleshooting exercises designed to develop hands-on skills in enterprise and WAN/LAN environments.

---

## 📝 Assignments Overview

1. **Assignment 1 – Network Models, Switching, and Basic Python Exercises**  
   Covers OSI vs TCP/IP models, TCP/IP layer functionalities, packet vs circuit switching, IP and MAC addressing, and basic Python exercises (prime number and palindrome checks).

2. **Assignment 2 – HTTP, DNS, and Client-Server Networking**  
   Focuses on HTTP connections (persistent vs non-persistent), DNS types and queries, client-server socket behavior, web page transfer analysis, and P2P file distribution timing.

3. **Assignment 3 – Transport Layer & Protocol Design**  
   Explores transport vs network layer services, multiplexing and de-multiplexing, TCP connection setup/termination, port assignments, and design of simple transport protocols.

4. **Assignment 4 – Go-Back-N, Selective Repeat, and TCP Congestion Control**  
   Investigates reliable data transfer protocols (GBN, Selective Repeat), TCP segment sequencing, acknowledgment strategies, congestion control algorithms (TCP Reno/Tahoe), and timing analysis.

5. **Assignment 5 – Subnetting, IP Addressing, and Enterprise Network Design**  
   Includes subnet calculations, subnetwork planning, DHCP conflict resolution, packet drop scenarios, and design of a high-level network architecture for a merged corporate network.

6. **Assignment 6 – Error Detection, CSMA/CD, Switch Operation, and Routing Algorithms**  
   Covers error detection techniques, slotted vs pure Aloha, learning switch operations, broadcast/collision domains, Dijkstra’s shortest-path algorithm, NAT, MAC/IP mapping, and jamming signals in CSMA/CD.
